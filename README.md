## 📡 데이터 — 좌표 검색이 없는 API 로 "내 주변"을 만들기

병·의원과 약국 정보는 공공데이터포털의 국립중앙의료원(응급의료정보원) 서비스에서 **앱이 브라우저에서 직접** 가져옵니다. 서버도 백엔드도 없습니다.

```
병의원  https://apis.data.go.kr/B552657/HsptlAsembySearchService/getHsptlMdcncListInfoInqire
약국    https://apis.data.go.kr/B552657/ErmctInsttInfoInqireService/getParmacyListInfoInqire
```

문제는 이 API 에 **좌표 반경 검색이 없다**는 점입니다. 조회 조건은 `Q0`(시도) · `Q1`(시군구) · `QT`(요일) 뿐이라, 좌표만 아는 앱이 쓰려면 **좌표 → 시군구 이름**을 스스로 옮겨야 합니다.

그래서 `scripts/build-districts.mjs` 로 시도별 기관 주소(`dutyAddr`)를 전부 훑어 시군구별 좌표 평균을 내고, **시군구 중심좌표 표 261개**를 `src/lib/districts.ts` 에 미리 구워 뒀습니다. 행정구역은 거의 안 바뀌니 1회성 배치입니다.

앱은 이 표에서 내 위치와 가까운 시군구를 골라 그 이름으로 조회합니다.

### 한계: 시군구 3곳까지만 (솔직하게)

`nearestDistricts()` 는 **반경 + 5km 안에 중심점이 들어오는 시군구를 가까운 순으로 최대 3곳**만 고릅니다. 다 받으면 좋겠지만 **평일 한 구가 2.8MB** 라 무작정 넓힐 수 없습니다.

그래서 **10km 반경에서는 원 바깥쪽이 비어 보이는 구간이 생깁니다.** 3곳으로 덮이지 않는 방향의 기관은 목록에도 지도에도 나오지 않습니다. 1km·3km 에서는 거의 문제되지 않고, 10km 는 "대충 이 방향에 뭐가 있나" 를 보는 용도로 생각하시면 됩니다.

캐시가 시군구 단위라, 나중에 이 `3` 만 올려도 구조는 그대로 씁니다.

처음엔 "가장 가까운 시군구 한 곳"만 조회했습니다. 시군구 중심점 기준이라, **강남역에 서 있으면 서초구 중심이 더 가까워서 서초구만 잡히고 강남구 병원이 전부 빠졌습니다.** 지도 오른쪽 절반이 텅 빈 채로 202곳만 나왔죠.

경계에 서 있는 게 특수한 상황이 아니라 도시에서는 평범한 상황입니다. 상위 3곳으로 고치니 같은 자리에서 502곳이 나왔습니다.
</details>

<details>
<summary><b>2. 시군구 목록에 섞여 있던 쓰레기 행 — 부산 서면에서 "부산광역시 부산광역시"가 이겼습니다</b></summary>

생성된 표에 **시군구명이 시도명과 똑같은 행이 3개** 있었습니다. 주소에서 시군구 토큰을 못 뽑은 기관들이 시도 이름으로 뭉쳐 한 덩어리가 된 것인데, 그 좌표 평균이 광역시 한복판에 찍힙니다.

그 결과 부산 서면에서 **"부산광역시 부산광역시" 가 445m 로 잡혀 진짜 부산진구를 이겼습니다.** 조회하면 `Q1` 이 안 먹어 엉뚱한 결과가 나옵니다.

수집 단계에서 시군구 토큰이 없는 주소를 버리도록 고쳤습니다. **세종은 원래 하위 시군구가 없어 정상**이라 남기고(조회할 때 `Q1` 을 빼는 예외가 이미 있습니다), 나머지를 걷어내 264 → **261개**가 되었습니다.
</details>

<details>
<summary><b>3. 병의원 API 의 광주·전남 이상 동작 — 두 API 가 서로 다른 시도명을 씁니다</b></summary>

병의원 API 데이터는 광주와 전남을 **`전남광주통합특별시`** 하나로 묶어서 줍니다. 실측하면 이렇습니다.

| 병의원 API `Q0` | 결과 |
|---|---|
| `광주광역시` | **7건** |
| `전남광주통합특별시` | **4,909건** |

반면 **약국 API 는 반대**로 `광주광역시` / `전라남도` 를 정상적으로 씁니다. 시군구 표는 병의원 API 로 만들었으니 표에는 `전남광주통합특별시` 가 들어 있고, 약국을 부를 때만 되돌립니다.

```ts
// src/lib/places.ts
const GWANGJU_GU = new Set(["동구", "서구", "남구", "북구", "광산구"]);
function sidoFor(kind: Kind, sido: string, gu: string): string {
  if (kind === 1 && sido === "전남광주통합특별시") {
    return GWANGJU_GU.has(gu) ? "광주광역시" : "전라남도";
  }
  return sido;
}
```

시군구 이름으로 광주 5개 구를 가려내 광주/전남을 갈라 보냅니다. 이걸 안 하면 광주·전남 사용자에게 약국이 거의 0건으로 나옵니다.
</details>

<details open>
<summary><b>4. 지도 핀 분포 — 반경을 바꿔도 지도가 그대로였습니다</b></summary>

서울 도심은 3km 안에 병원이 800곳 넘습니다. 다 찍으면 도로도 지명도 안 보이는 파란 덩어리가 됩니다. 그래서 지도에는 **최대 50개**만 찍기로 했는데, 처음엔 **거리순 상위 50개**를 골랐습니다.

이게 조용한 버그였습니다. 도심에서는 가까운 50개가 전부 1km 안쪽에 몰려 있어서, **3km 로 바꾸든 10km 로 바꾸든 지도에 찍히는 핀이 거의 그대로**였습니다. 반경 버튼이 동작하지 않는 것처럼 보였죠(목록은 멀쩡히 바뀌고 있었는데도요).

`spreadOut()` 으로 바꿨습니다 — **반경을 가로 10칸 격자로 쪼개고, 칸마다 가장 가까운 한 곳만** 남깁니다.

```ts
// src/components/MapView.tsx
const cellM = (radius * 2) / GRID_CELLS_ACROSS;   // 반경이 커지면 칸도 커짐
// …내 위치 기준 (x, y) 칸을 계산해 이미 채운 칸은 건너뜀
```

칸 크기가 반경에 비례하니 반경을 넓히면 핀도 넓게 퍼집니다. 잘라 찍었다는 사실은 지도 위 **"일부만 표시 · 전체는 목록에서"** 배지로 밝힙니다 — 말없이 빼면 "목록엔 있는데 지도엔 왜 없지" 가 됩니다.
</details>

<details>
<summary><b>5. 상세 카드가 지도 밑에 깔렸던 버그</b></summary>

핀을 눌러도 아무 일이 안 일어나는 것처럼 보였습니다. 실제로는 카드가 그려지고 있었는데, **Leaflet 이 타일·마커 pane 을 z-index 400~700 에 깔아 놓기 때문에** z-index 를 안 준 카드가 지도 아래로 들어간 것이었습니다.

상세 카드와 "지도를 불러오지 못했어요" 안내 모두 `z-index: 1000` 으로 올렸습니다. 상세는 딤 없는 얕은 카드로 띄웁니다 — 딤이 있는 바텀시트를 쓰면 카드가 떠 있는 동안 지도를 못 움직입니다.
</details>

<details>
<summary><b>6. 타일 실패 판정 — 한두 장 빠지는 건 정상입니다</b></summary>

타일은 원래 가끔 빠집니다. `tileerror` 한 번에 "지도를 못 불러왔어요" 를 덮으면, 멀쩡히 그려진 지도 위에 오류 안내가 뜹니다. **한 장이라도 성공했으면 지도는 쓸 수 있는 상태**로 보고, 단 한 장도 못 받았을 때만 안내를 띄우고 목록 탭으로 안내합니다.
</details>

## 🕐 진료시간 판정 — 여기가 틀리면 최악입니다

"열었대서 갔는데 닫힌" 게 이 앱에서 나올 수 있는 가장 나쁜 결과라, 판정 로직(`src/lib/schedule.ts`)은 따로 떼어 자체 점검을 붙였습니다.

API 의 `dutyTime1s/1c` ~ `dutyTime8s/8c` 를 **8칸 시간표 `[월,화,수,목,금,토,일,공휴일]`** 로 줄여서 씁니다.

| 값 | 뜻 | 화면 표기 |
|---|---|---|
| `"0900-1800"` | 그 요일 진료 | 지금 진료 / 지금 휴진 |
| `""` | 그 요일 **휴무** | 지금 휴진 |
| 값 없음 | **정보 없음** | 시간 정보 없음 |

**"휴무"와 "정보 없음"을 구분하는 게 핵심입니다.** 시간표가 비어 있는 기관이 꽤 있는데, 이걸 휴무로 단정하면 실제로 문 연 병원이 목록에서 사라집니다. 그래서 시작·종료 중 한쪽만 있거나 형식이 깨진 값도 휴무가 아니라 `unknown` 으로 둡니다. "지금 열린 곳" 필터도 **휴진만 걸러내고 정보 없음은 남깁니다.**

**자정을 넘기는 시간표**(24시 약국의 `0900-0300` 같은)는 종료가 시작보다 작거나 같으면 넘김으로 보고 판정합니다.

```bash
npm run check:schedule
```

요일 인덱스 변환, 시작·종료 경계(18:00 정각은 종료), 토·일 휴무, 공휴일 칸, 자정 넘김, 빈 시간표, 깨진 형식, 라벨 문자열까지 assert 로 확인합니다.

**반영하지 못하는 것:** 점심시간 휴진은 8칸 시간표에 담기지 않아 계산에 넣지 못합니다. 공휴일 칸(8번째)을 읽는 로직은 있지만, 현재 화면은 항상 평일 기준으로 조회합니다 — 공휴일 자동 판별을 붙이려면 공휴일 달력이 따로 필요합니다.

> ⚠️ **진료시간은 기관이 등록한 값입니다.** 임시 휴진, 예약 마감, 진료과 사정으로 실제와 다를 수 있어요. 앱에도 "방문 전 전화로 꼭 확인하세요" 를 상시 노출하고, 앱은 병원을 추천하거나 평가하지 않습니다. 거리는 걷는 거리가 아니라 직선거리라 실제로는 더 멉니다.

## 💾 캐시와 다시 찾기

**캐시** — `(종류, 시도, 시군구, 요일, KST 날짜)` 단위로 `localStorage` 에 담습니다.

```
open-clinic:places:0:서울특별시:강남구:5:2026-08-15
```

날짜가 키에 들어 있어 **자정이 지나면 자연히 새로 받고**, 같은 날 앱을 다시 열면 API 를 부르지 않습니다. 용량 초과로 저장이 실패해도 조용히 넘어갑니다 — 캐시가 안 돼도 앱은 동작해야 하니까요.

**점진적 표시** — 가까운 시군구부터 순서대로 받고, 한 구가 끝날 때마다 화면을 갱신합니다. 첫 화면이 뜰 때까지 나머지 구를 기다리게 하지 않습니다.

**다시 찾기** — 이동 중에 위치가 바뀌었을 때 쓰는 버튼입니다. 첫 로딩과 달리 화면을 통째로 갈지 않아서, 실패해도 갖고 있던 목록이 그대로 남고 안내 문구만 3초간 뜹니다. 같은 시군구 안에서 움직였으면 캐시를 그대로 쓰고, **거리와 진료중 여부는 그 시각 기준으로 항상 다시 계산**합니다. 탭·반경·병원/약국 선택은 유지됩니다.

## 🗺 지도 — 지도사 SDK 를 쓰지 않은 이유

이 앱에서 지도가 하는 일은 **핀 찍기와 반경 원 그리기**가 전부입니다. 그래서 **Leaflet + OpenStreetMap** 으로 끝냈습니다. 인증키도 도메인 등록도 필요 없고, 타일 주소 한 줄(`src/lib/env.ts` 의 `TILE_URL`)만 바꾸면 지도를 통째로 갈아끼울 수 있습니다.

Leaflet 기본 마커는 이미지 파일을 따로 물어서 번들 경로가 깨지기 쉬워, 핀은 `divIcon` 으로 직접 그립니다. 내 위치는 마커가 아니라 작은 원으로 그리고, 핀을 다시 그릴 때마다 맨 위로 올립니다 — 도심에서는 핀이 내 위치를 덮어버립니다.

> ⚠️ OSM 공식 타일 서버는 이용 정책상 대량 트래픽을 허용하지 않습니다. 사용자가 늘면 타일 제공자를 따로 두거나 직접 호스팅해야 합니다.

**배너 2지면이 전부입니다. 전면·리워드 광고는 넣지 않았습니다** — 아파서 병원을 찾는 사람에게 광고를 보게 하고 결과를 열어주면 앱을 지웁니다.

30초인 이유: 토스 배너는 AdMob 기반이고, **AdMob 은 30초보다 잦은 갱신을 무효 트래픽으로 봅니다.** 화면이 가려져 있는 동안(`visibilitychange`)에는 갱신을 멈춥니다 — 안 보이는 동안 돌리면 노출로 잡히지 않고 호출만 쌓입니다.

이미지형 자리는 소재가 잘리지 않도록 고정 높이가 아니라 최소 높이로 잡았고, 하단 고정 배너는 반대로 고정 높이입니다(위로 자라면 본문을 덮습니다). 광고그룹 ID 가 비어 있으면 배너는 그려지지 않고 **자리 자체를 만들지 않아** 빈 여백이 남지 않습니다.

## 🛠 기술 스택

| 영역 | 사용 기술 |
|---|---|
| **언어** | TypeScript 5.7 (strict) |
| **프론트엔드** | React 18, Vite 6 |
| **지도** | Leaflet 1.9 + OpenStreetMap 타일 |
| **플랫폼 SDK** | `@apps-in-toss/web-framework` 3.0.2 (위치 · 인앱광고 · 외부 링크 · 이벤트로그) |
| **데이터** | 공공데이터포털 병·의원/약국 API 를 브라우저에서 직접 호출 — **서버 없음** |
| **상태** | 화면 로컬 상태 + `localStorage` 캐시 |
| **수익화** | 인앱 광고(배너 2지면) |

**권한은 위치 하나뿐입니다.** 로그인이 없고, 위치 좌표는 거리 계산과 시군구 선택에만 쓰고 어디로도 보내지 않습니다.

XML 파싱은 라이브러리를 들이지 않았습니다. 이 API 는 JSON 옵션이 없어 XML 만 주는데, 필요한 건 평평한 `<item>` 목록과 `<totalCount>` 뿐이라 정규식 40줄(`src/lib/xml.ts`)로 끝냅니다. 인증키가 틀리면 `<returnAuthMsg>` 만 오는데, 이건 조용히 0건으로 넘기지 않고 에러로 올려 보냅니다.

## 🚀 개발

```bash
npm install
npm run dev             # 브라우저 (광고는 미지원 환경으로 자동 우회)
npm run check:schedule  # 진료시간 판정 자체 점검
npm run districts       # 시군구 중심좌표 표 재생성 (1회성 배치, EGEN_KEY 필요)
npm run typecheck
npm run build           # vite build + ait build → open-clinic.ait
npm run deploy
```

루트에 `.env` 를 만들고 공공데이터포털 인증키(`VITE_DATA_KEY`)와 콘솔에서 발급받은 광고그룹 ID(`VITE_AD_GROUP_ID_BANNER`, `VITE_AD_GROUP_ID_BANNER_IMAGE`)를 채우세요. 광고 ID 를 비워두면 배너 자리가 아예 생기지 않아 브라우저 개발이 끊기지 않습니다.

> ⚠️ `VITE_` 변수는 빌드 시점에 번들로 구워집니다. 즉 **공공데이터 인증키는 배포된 코드 안에 그대로 노출됩니다.** 이 키는 일일 호출 한도만 있고 결제·개인정보 권한이 없는 무료 키라 노출 절충을 받아들인 상태입니다. 감추려면 프록시 한 대를 세워 키를 백엔드로 옮기면 됩니다. 값을 바꾸면 반드시 다시 빌드하세요.
